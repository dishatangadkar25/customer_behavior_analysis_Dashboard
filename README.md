# Customer Trend Analysis – Data Analytics Project

## 📌 Overview

**Customer Trend Analysis** is an end-to-end data analytics project focused on understanding customer purchasing behavior, product performance, discounts, subscriptions, shipping preferences, and customer segments.

The project follows a complete analytics workflow:

**Dataset → Python → EDA & Data Cleaning → MySQL → SQL Analysis → Power BI Dashboard → Report → Presentation**

The project demonstrates practical skills in **Python, SQL, MySQL, Power BI, Excel-style data analysis, data visualization, and business reporting**.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Understand revenue and purchase patterns.
* Identify top-performing products.
* Analyze product ratings and customer reviews.
* Study the impact of discounts on purchases.
* Compare customer spending based on subscription status.
* Analyze shipping preferences and purchase amounts.
* Segment customers into New, Returning, and Loyal customers.
* Present insights through an interactive Power BI dashboard.

---

## 📊 Dataset

**Dataset:** Customer Shopping Behavior

The dataset contains customer-level shopping information, including details related to:

* Customer ID
* Age
* Gender
* Category
* Item Purchased
* Purchase Amount
* Review Rating
* Shipping Type
* Discount Applied
* Subscription Status
* Frequency of Purchases
* Previous Purchases

### Data Preparation

The dataset was prepared in Python using Pandas.

Key cleaning and transformation steps included:

* Checking dataset structure using `info()`.
* Performing descriptive analysis using `describe()`.
* Checking missing values.
* Filling missing **Review Rating** values using the median rating within each category.
* Standardizing column names.
* Renaming `purchase_amount_(usd)` to `purchase_amount`.
* Creating an **Age Group** column.
* Converting purchase frequency into purchase-frequency days.
* Removing the duplicate `promo_code_used` column after checking its relationship with `discount_applied`.

## ▶️ How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-link>
cd customer-trend-analysis
```

### 2. Install Python Libraries

```bash
pip install pandas sqlalchemy pymysql
```

### 3. Open the Jupyter Notebook

Open:

```text
customer_trend_analysis.ipynb
```

Make sure the dataset file is available in the same project folder.

### 4. Run the Python Analysis

Run the notebook cells to:

* Load the dataset
* Perform EDA
* Clean the data
* Create new analytical columns
* Connect Python with MySQL
* Load the cleaned dataset into MySQL

### 5. Set Up MySQL

Create the database:

```sql
CREATE DATABASE mydatabase;
USE mydatabase;
```

Run the SQL file:

```text
d33c7697-23fc-4c8a-b6cb-10a2654479b1.sql
```

### 6. Connect Power BI

Open Power BI Desktop and connect it to the MySQL database.

Use:

```text
Database: mydatabase
Table: mytable
```

Then build or refresh the dashboard using the cleaned data.
